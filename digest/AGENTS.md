# Дайджест новостей

React 19, TypeScript, Vite 8. Тесты — Vitest и Testing Library (не Jest).

## Как работать

- Изменения в файлы вносишь инструментами правки, а не кодом в ответе.
- Перед правкой читаешь файл целиком.
- После правок запускаешь `npm run lint -- --deny-warnings`, `CI=true npm test` и исправляешь ошибки.
- В конце коротко перечисляешь, какие файлы изменены и что проверено.

## Формат данных

Адрес веб-приложения задаётся переменной `VITE_DIGEST_URL` в `.env`, строкой в коде его нет.
Ответ — JSON вида `{"news": [...]}`. Поля новости: `id`, `date` (ISO), `source`, `title`, `summary`, `tags`, `link`.
Теги приходят **строкой** «ИИ, наука» — превращать в массив, разбивая по запятой. Ключ записи и токен бота в код не попадают.

## Правила кода

- Компоненты — функции; хуки вызываются в начале компонента, до любого return.
- Отфильтрованный список вычисляется при отрисовке, в состоянии хранятся только поиск, тег, флажок и отметки «прочитано».
- Отметки «прочитано» хранятся в `localStorage` под ключом `digest-read`.
- Загрузка — один `useEffect` с флажком `ignore`; состояния: список, загрузка, ошибка.
- Сообщение о загрузке — `role="status"`, об ошибке — `role="alert"`, пустой результат — «Новостей не найдено».
- У полей ввода есть `<label>`; не заменять подписи атрибутом aria-label.
- Тексты интерфейса — на русском языке. Ссылка на новость открывается в новой вкладке с `rel="noreferrer"`.
- Тесты лежат рядом с файлом: `*.test.tsx`; сеть подменяется `vi.stubGlobal('fetch', …)`.
