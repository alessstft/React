# Задание 2. Поиск, тег и «только непрочитанные»

## Что сделать

Над лентой — поле поиска по заголовку и пересказу без учёта регистра, выбор одного тега, флажок «Только непрочитанные». Всё работает вместе. Под фильтрами — счётчик «Показано X из Y». Если ни одна новость не подходит — строка «Новостей не найдено».

## Правила проекта

- Отфильтрованный список вычисляется при отрисовке; в состоянии хранятся только текст поиска, выбранный тег и флажок.
- Список тегов собирается из всех новостей, первый вариант — «Все».
- Счётчик считает все новости и показанные после фильтров.
- Карточки остаются ссылками; у полей есть подписи `<label>`, всё доступно с клавиатуры.
