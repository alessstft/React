# Задание 3. Отметка «прочитано»

## Что сделать

У каждой карточки — кнопка «Отметить прочитанным». Повторное нажатие снимает отметку, на кнопке появляется «Прочитано ✓», карточка становится бледнее. Отметки сохраняются в `localStorage` под ключом `digest-read` и не пропадают после перезагрузки страницы.

## Правила проекта

- В состоянии хранится массив `id` прочитанных новостей; при изменении он сразу записывается в `localStorage`.
- При первом открытии состояние берётся из `localStorage`; повреждённое значение не ломает страницу.
- Флажок «Только непрочитанные» из задания 2 учитывает этот массив.
- Кнопка доступна с клавиатуры и имеет понятное название.

## Готово, когда

- `npx tsc -b`, `npm run lint -- --deny-warnings`, `CI=true npm test` — без ошибок;
- в `src/App.test.tsx` добавлены тесты: отметка ставится и снимается, отметка сохраняется после повторного показа страницы, фильтр «Только непрочитанные» скрывает прочитанное;
- `npm run dev`: отметить новость, обновить страницу — отметка на месте.
