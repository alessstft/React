# Дайджест новостей

Проект модуля 4: лента новостей из Google Таблицы, поиск, фильтр по тегу и отметка «прочитано».

## Запуск

```powershell
npm install
Copy-Item .env.example .env
npm run dev          # http://localhost:5173/digest/
npm test
npm run build
```

В `.env` впиши адрес веб-приложения Apps Script, оканчивающийся на `/exec`:

```
VITE_DIGEST_URL=https://script.google.com/macros/s/…/exec
```

Адрес виден каждому, кто открыл сайт, поэтому его можно хранить и в секрете репозитория — так он попадёт в сборку на GitHub Actions. **Ключ записи** в репозиторий не попадает: он нужен только n8n.

## Что умеет страница

- загружает `{"news": [...]}` один раз при открытии, сортирует от свежих к старым;
- строка тегов «ИИ, наука» превращается в отдельные метки;
- поиск по заголовку и пересказу без учёта регистра, выбор одного тега, флажок «Только непрочитанные» — работают вместе;
- счётчик «Показано X из Y» считает все новости и показанные;
- кнопка «Отметить прочитанным» снимается повторным нажатием, отметки хранятся в `localStorage`;
- загрузка — `role="status"`, ошибка — `role="alert"` с кодом ответа, пустой результат — «Новостей не найдено».
