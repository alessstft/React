# Журнал работы с ИИ · проект П4

## 20.11.2026 · дайджест новостей

Инструмент: встроенный ИИ-агент в редакторе, режим Р2 (код пишет агент, я ставлю задачи и принимаю работу).
Правила проекта: `AGENTS.md`. Задания: `tasks/01-zagruzka.md`, `tasks/02-filtry.md`, `tasks/03-prochitano.md`.

### Задание 1 — загрузка и карточки
Агент прочитал `App.tsx` и предложил код в чате, не изменив файлы. `git status` пустой, тестов нет.
**Отклонено**: раздел «Готово, когда» не выполнен. Взята из ответа идея сортировки через `new Date(b.date) - new Date(a.date)`, функция `loadDigest` и два теста написаны вручную.

### Задание 2 — поиск, тег, флажок
Агент попытался хранить отфильтрованный список в `useState` и копировать его через `useEffect`.
**Отклонено**: правило «состояние без дублей» из `AGENTS.md` и главы 4.3. Оставлен вариант с вычислением `shown` при отрисовке — после поиска «ИИ» счётчик всё равно показывает все новости.

### Задание 3 — «прочитано»
Агент записал отметки в `localStorage` при каждом рендере, из-за чего состояние зацикливалось.
**Отклонено**: запись перенесена внутрь функции изменения состояния, добавлена защита `try/catch` при чтении.

### Решение
Правки агента отменены (`git checkout -- .`); три задания закрыты вручную. Из ответов агента взяты: сортировка по дате, сценарии тестов и набор тегов из строки «ИИ, наука».
Проверено: `npx tsc -b`, `npm run lint -- --deny-warnings`, `CI=true npm test` (5 тестов), `npm run build`, проход страницы клавишей Tab. Ключ записи Apps Script и токен бота в код и журнал не попали.
