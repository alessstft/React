# Справочник по Angular и React · моя работа

Учебная дисциплина «Фронтенд в эпоху ИИ», справочник
[М. Н. Макарова](https://maximbytecamp.github.io/angular_react_makarov/).
Первый модуль уже залит на GitHub, второй добавила новым коммитом — это
продолжение того же проекта `zayavki`.

## Модули

| Модуль | Тема | Что сдаю |
| --- | --- | --- |
| **1** | React: первый проект и первый бот | доска заявок на Vite + React + TypeScript, localStorage, вебхук n8n → Telegram |
| **2** | Данные с сервера и ИИ-диспетчер | PocketBase, загрузка с ошибкой и повтором, хук `useRequests`, обновление по событиям, Ollama + кнопка «Взять» |

Проверочные работы (Тест 1 и Тест 2) сдаю отдельно, в репозиторий их не включала.

## Как запускаю

```powershell
cd "C:\Users\aless\OneDrive\Desktop\Angular и react\zayavki"
npm install
npm run dev          # http://localhost:5173
```

Серверная часть поднимается отдельно, из папки `avtomatizaciya`:

```powershell
cd "..\avtomatizaciya"
docker compose up -d --build
docker compose ps
```

PocketBase — `http://localhost:8090/_/`, n8n — `http://localhost:5678`,
Ollama — `http://localhost:11434`. Перед первым запуском копирую
`.env.example` в `.env` и вписываю токен бота; сам `.env` в Git не коммитится.

## Проверка перед сдачей

```powershell
npm run build
npm run lint
```

Обе команды прогнала на Node.js 26.13.1 / npm 11.20.0, Vite 8.3.8,
React 19.3.1, TypeScript 7.0.2, Oxlint 1.94.0 — ошибок и предупреждений нет.
Доску проверила в браузере с запущенным PocketBase: пять заявок из базы,
счётчик и заголовок вкладки, добавление без дублей, фильтр и Esc,
обновление статуса без F5 по подписке, сообщение об ошибке и кнопка
«Повторить» при остановленном сервере.

## Что осталось перед защитой

1. Создать `.env` с токеном бота и скачать модель `qwen2.5:3b` (образ Ollama
   занимает около 7 ГБ, модель — 2,1 ГБ).
2. Опубликовать в n8n два процесса из `avtomatizaciya/`, сняв с публикации
   процесс модуля 1 — у них один адрес вебхука `/webhook/zayavka`.
3. Уточнить у преподавателя вариант службы для проекта П2. Сейчас стоит
   базовый «ИТ-отдел колледжа»; что менять под общежитие или студсовет,
   расписано в `modul-2/README.md`.
4. Приложить снимки сообщения бота с кнопкой «Взять» и после нажатия.
5. Вписать ФИО, группу и преподавателя в оба отчёта.
   Перед архивацией удаляю `node_modules` и `dist`.
